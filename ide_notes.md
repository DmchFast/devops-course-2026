# Git в VS Code vs терминал

## Что удобно в VS Code

1. **Визуальный diff.** Открываешь файл — сразу видно, что добавлено (зелёным), что удалено (красным), без `git diff` в терминале.

2. **История и blame через GitLens.** Можно навести курсор на любую строку кода и увидеть, кто её написал, когда и в каком коммите. В терминале это делается через `git blame`, но читать менее удобно.

3. **Быстрые действия в один клик.** Stage, commit, push, переключение веток — всё через кнопки. Не нужно помнить синтаксис команд.

## Что удобнее в терминале

- **Сложные операции: rebase, cherry-pick, squash, работа с конфликтами в нестандартных сценариях.** VS Code эти команды либо не поддерживает, либо скрывает, либо делает неочевидно. В терминале полный контроль и видно каждое действие Git.
