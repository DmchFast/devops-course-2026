# Мой пет-проект

Идея: Консольная утилита на C# для учёта личных расходов. Пользователь добавляет траты командой `add <сумма> <описание>`, просматривает список и получает сумму за месяц. Данные сохраняются в JSON-файл, чтобы не теряться между запусками.

Стек: C# 12, .NET 8, System.Text.Json, LINQ.

Цель: научиться работать с файловой системой, сериализацией JSON, разбором аргументов командной строки и запросами LINQ для подсчёта статистики.

## MVP
- Добавление расхода (`add 250 кофе`)
- Просмотр списка (`list`)
- Подсчёт суммы за месяц (`total`)
- Сохранение данных в JSON
